## 自动构建与 Release

已发布的固件见 [Releases](https://github.com/niu541412/aDataFlow/releases)。下载名称带 `-full.bin` 的完整镜像，烧录地址为 **`0x0000`**（ESP32-S3 N8R2，DIO、80 MHz、8 MB Flash）。该镜像已合并引导程序、分区表和应用，可能重置原有设置。附件 `SHA256SUMS.txt` 可用于校验。

GitHub Actions 会在推送到 `main` 或推送 `v*` 标签时构建。发布新版本只需：

1. 修改 `include/main.h` 中的 `FIRMWARE_VERSION`，例如 `1.4.0`。
2. 在 `CHANGELOG.md` 中添加同版本的更新记录。
3. 提交并推送到 `main`，工作流会创建 `v1.4.0` 标签和 Release，上传从 `0x0000` 烧录的完整固件。也可自行推送同名标签，但标签版本必须与头文件一致。

已有的公开 Release 不会被覆盖；版本号未变的提交只生成构建产物。手动运行工作流也只构建，不发布。默认的 `GITHUB_TOKEN` 已在 workflow 中声明 `contents: write`，不需要另配个人令牌。

板卡定义直接使用项目内 `others/Boards`，无需复制到个人目录。已锁定当前验证过的框架和库版本。

本地构建、边界检查与合并：

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install platformio==6.2.0
pio run -e esp32s3dev_n8r2
python scripts/run_host_checks.py --ui-layout
python scripts/firmware_release.py package
```

完整镜像和校验文件输出到 `dist/`。存在未提交改动时，镜像名称带 `-local`，用于区分本地测试版和已发布固件。边界检查需要 `clang++` 或 `g++`；`--ui-layout` 还需要 CMake，用于链接实际 LVGL 和字体检查图例布局。只构建固件和合并镜像不需要这些主机测试工具。


## 图表配置行长度

1.3.1 起允许一行包含最多 **2048 字节有效内容**，CR/LF 换行不占该额度。这是软件缓冲限制，可在 `include/uart.h` 中调整；队列使用固定内存预算，增大单行上限会减少可排队的记录数。已发布的 1.3.0 仍使用旧的 352 字节限制。


## 数据页 ASCII / HEX（1.4.0）

数据页滚动旋钮长按至少 **2 秒后松开**切换 ASCII / HEX，左下角不显示模式字样；短按保留回到最新数据的操作。切换立即作用于缓存的最近 50 条历史，不需要等待新数据，曲线解析及 SD 录制不受显示格式影响。

HEX 连续显示字节，相邻字节用两种文字颜色区分，不插入空格；通过绘制事件直接给字节上色，不在文本中放置颜色命令，换行以完整字节为单位。RX 保留浅色/青色交替，TX 保留琥珀色/浅色交替；切回 ASCII 后按原文显示，文字中的 `#` 不会被当作颜色命令。HEX 每条显示前 256 字节，超出部分以 `... (+N bytes)` 提示，避免长报文换行后超出列表坐标范围；完整采集行仍保留，可切回文本查看。HEX 显示当前采集队列保留的行结束字节；现有 CRLF 组帧会合并行尾，不保证逐字节复现线上所有 CR/LF。当前仍按换行组帧，尚未扩展为任意二进制流采集，原有 SD 字符串录制也不保证保留 NUL 字节。


## 手机配网与曲线时间（1.4.0）

- 未配网时开机自动启动手机配网，支持 ESPTouch / AirKiss（非 ESPTouch v2）；手机连接 2.4 GHz Wi-Fi 后发送配网信息。固件不内置 SSID 或密码，配网信息由设备保存，重启后自动连接。
- 波特率旋钮长按至少 5 秒启动重新配网，录制灯以 15% 亮度快速闪两次提示；短按仍启动或取消自动测速。配网窗口 3 分钟，超时可再次长按启动。
- 顶栏最左侧、波特率前的 Wi-Fi 图标与顶栏文字同色：右下角 `?` 表示配网中、`...` 表示连接中、`x` 表示未连接或失败，已连接时不附加标记。后台断线重连，联网后 NTP 校时；右下角仅显示最新数据时间，未校时隐藏。
- 曲线区域左下角显示已有样本的实际时间跨度，如 `-6.5min`、`-1hr`；没有样本时显示 `--`。右下角联网校时后显示最新数据的北京时间（UTC+8，HH:MM:SS），未校时隐藏，无新数据时保持最后一条数据的时间，已校时后的短暂断网仍继续计时。两个时间标签均为透明背景。
- 时间戳取完整 UART 行入队的本机单调时间；跨度按实际缓存样本的最早/最新时间计算。横轴仍按样本等距排列，不代表中间各点具有相等时间间隔。
- 录制常亮、无卡/录制错误闪灯统一使用约 15% 占空比，配网提示闪灯也保持该亮度。录制灯为 GPIO3 的单色灯，使用 LEDC 通道 6 / 定时器 3，5 kHz、8 bit、占空比 38/255；不影响 LCD 背光的通道 1 / 定时器 0。
- 显示双 DMA 缓冲使用 16 行，比原来释放 43,520 字节内部 RAM；GPIO39/45 已显式配置输入，消除供电/关机检测时的未初始化警告。UART 接收回调只累计丢弃计数，由监控任务汇总；SDK 配网确认任务栈独立增至 6 KB，以修复已捕获的两类栈溢出。
